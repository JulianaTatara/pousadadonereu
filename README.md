# Pousada do Nereu — Site V3

Versão V3 do protótipo desktop-first da Pousada do Nereu.

## Abrir localmente
1. Abra esta pasta no VS Code.
2. Confie na pasta (`Trust this folder`) se o VS Code estiver em Restricted Mode.
3. Instale/ative a extensão Live Server.
4. Clique com o botão direito em `index.html` > `Open with Live Server`.

## Direção visual V3
- Fundo principal quente: `#F2EBDD`.
- Azul como cor institucional principal.
- Laranja/âmbar/terracota em CTAs e detalhes.
- Texturas discretas, curvas e composição mais editorial.
- Header fixo, logo maior, seletor 🇧🇷 PT / 🇺🇸 EN / 🇪🇸 ES.
- Menu: Início, A Pousada (dropdown), Acomodações, Valores, Marina, Como Chegar, Marés, Contato.

## CMS
Este pacote ainda é HTML/CSS/JS estático. A estrutura visual foi pensada para futura integração com CMS, permitindo editar fotos, textos, legendas, preços, equipe e galerias sem mexer no layout.
