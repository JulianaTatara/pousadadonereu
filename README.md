# Pousada do Nereu

Nova versão do site da Pousada do Nereu.

## Estrutura
- `content/pt.json` e `content/en.json`: textos e dados editáveis.
- `assets/uploads/`: imagens e vídeos enviados pelo CMS.
- `.pages.yml`: configuração do Pages CMS.
- `netlify.toml`: configuração de publicação no Netlify.

O site é estático e não precisa de banco de dados.
